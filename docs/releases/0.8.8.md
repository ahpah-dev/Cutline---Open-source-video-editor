# Cutline 0.8.8 — Color your canvas. Shape your captions.

Two editing updates in one free, watermark-free Windows release.

## Customizable Whisper caption line length

- In **Captions → Auto subtitles**, choose **Words per line** from 1–20. Quick presets: 1, 3, 5 and 7 words.
- Your choice is remembered locally and shown in a live example. Existing captions are untouched; new captions remain normal editable text clips.
- Real Tiny word timings are retained. Large's multiword segments are split into shorter cards with **estimated** within-segment timing. Speech pauses can produce fewer words than the selected maximum.
- Text-only transcription fallback now retains the decoded audio duration after its sample buffer is transferred to the worker. Consecutive caption cards do not retain overlapping minimum display tails.
- Generation remains local, with the same Tiny/Large model choices. No new model download or paid transcription API is required by this setting. Review recognition and timing before export.

## Gradient canvas backgrounds

- Deselect the current layer and open **Inspector → Canvas background**. Choose Solid, Linear or Radial.
- Six palettes; 2–8 exact hex colors; editable stop positions; add/remove/reverse controls.
- Linear angle, radial center and radius, keyboard-accessible controls, normal Undo/Redo.
- Included in project backups, autosave, AI previews and offline MP4/WebM exports. Old projects retain their solid backgrounds; switching to Solid preserves the gradient settings.
- Gradients render behind layers, letterboxing, transparency and timeline gaps. Empty-player hints no longer dim their preview. A background does not add timeline duration on its own.
- AI tools can inspect and precisely edit `backgroundFill` with the same strict, atomic revision checks.

## Verification and downloads

Unit/component and native protocol tests, real rendering/export regression checks, and isolated Windows UI flows cover both updates. The caption UI flow uses a deterministic transcription-worker fixture with real local audio decoding; it does not claim a new accuracy benchmark for the unchanged Whisper models.

Use **Cutline-Setup-0.8.8-x64.exe** to install/update, or **Cutline-Portable-0.8.8-x64.exe** for the portable build. Verify downloads with **SHA256SUMS.txt**. Windows x64; the installers are unsigned and may trigger SmartScreen. Existing projects and model caches are not removed by this release.
