# Cutline 0.8.4 — Frame-accurate export and library cleanup

Cutline stays free, local and watermark-free. This release replaces live-recording export with offline frame rendering and adds safe media/project deletion.

- **Constant-frame-rate export:** each frame renders at an explicit timeline timestamp. Slow effects or decoding take longer instead of silently dropping frames. Encoding uses backpressure and validates packet count and timing before saving.
- **Source-accurate rendering:** independently decoded video frames support trims, speed changes, freezes, repeated sources and two-sided transitions. MP4/H.264 and WebM/VP9/VP8 are supported where codecs are available.
- **Synchronized audio:** bounded-window mixing preserves volume automation, fades, stereo pan, muted layers and transition crossfades. Basic pitch-preserving speed processing is included.
- **Delete media:** trash buttons in Media and Audio remove assets and linked clips in one undoable edit, with confirmation and locked-layer protection. Original files and other projects remain untouched.
- **Delete projects:** Project → My projects lets you permanently remove a saved project, with confirmation. Shared assets remain; only unused imported copies are reclaimed. Deleting the open project creates a fresh workspace, and stale autosaves cannot recreate deleted projects.
- **Cancel export:** cancellation disposes decoding/encoding resources without saving a partial result. Unsupported codecs fail explicitly instead of producing missing frames or silently absent audio.

Verification includes 93 unit/component checks, 15 font/Codex protocol checks and the full 89-check render/export suite. Export stress tests cover all three formats at 30/60 fps under deliberate rendering stalls, including decoded-audio beat synchronization. A production Windows UI export from the packaged app saved exactly 960 frames at 60 fps over 16 seconds with audio; native saving and cancellation passed. Media/project deletion is tested through real IndexedDB and the packaged production UI in isolated profiles, including Undo, project reset and layout at 1100/1480 pixels. Type checking, scoped lint, desktop/web builds and server rendering passed. Earlier live AI and Whisper model checks were not repeated.

Limitations: this prevents render-load-induced dropped frames, not every cause of choppy playback. It does not repair already-stuttering source footage or interpolate low-frame-rate footage. Demanding files still need a capable playback device. Export files are currently assembled in RAM; long/high-bitrate projects can use substantial memory. Extreme audio retiming can introduce artifacts. Keep the app open and PC awake while exporting. Project deletion is permanent: back up first.

Download **Setup** to install or **Portable** to run without installation. Windows x64 builds are unsigned and may trigger SmartScreen. Verify downloads with SHA256SUMS.txt. Optional Codex editing uses your own account and usage limits.
