# Cutline 0.8.6 — Timeline/audio synchronization

- Rapid scrubbing keeps the latest seek target while media is still decoding.
- Play waits for the final source position, audio initialization, a prepared preview frame and media playback readiness. Obsolete startup work cannot resume an old seek.
- The playhead follows actual media playback, preferring audible audio, with trims, clip placement and speed accounted for. It no longer runs on an independent wall timer while audio is loading.
- Decoder seeks and buffering pause the whole transport, keeping overlapping songs and video together. Drift correction uses 40 ms of timeline time instead of the former 180 ms source-time allowance.
- Silent-gap playback stops at the next source boundary rather than skipping short clips after a late UI frame.
- Playhead timestamps are read after preview rendering and committed immediately at a bounded cadence to avoid delayed pre-stall UI updates.

Validation: 97 unit/component checks, 21 native/protocol checks and 96 render/playback/export checks passed, plus the server-rendered shell (215 total). The final six transport checks were rerun after the UI timestamp change. Native Windows drag/release → Play and deliberate 100 ms UI-stall checks passed twice consecutively with generated media in an isolated profile. Desktop/web builds, type checking and scoped lint passed. These tests do not measure physical speaker or Bluetooth latency.

This addresses persistent internal synchronization drift, not all preview frame drops, hardware latency or unsupported codecs. An overloaded renderer cannot draw while blocked; it catches up to the media clock on its next update. Offline frame-accurate and disk-backed Windows export remain unchanged.

Download Setup for installation or Portable to run without installing. Windows 10/11 x64 builds are unsigned and may trigger SmartScreen. Verify downloads using SHA256SUMS.txt. Installing an update preserves local projects and original media; no automatic installation is performed by this release workflow.
