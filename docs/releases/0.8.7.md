# Cutline 0.8.7 — Your models, your edit

- Custom AI APIs alongside Codex: configurable base URL, optional Bearer API key, connection name and model/router combo ID.
- One-click local 9Router preset, model discovery via GET /models, and manual IDs for APIs that omit discovery.
- OpenAI-compatible Chat Completions and tool-calling models use the same precise, revision-checked, atomic and undoable editing tools as Codex. No shell or arbitrary file access.
- Optional real image inputs and provider-compatible Low/Medium/High reasoning controls. Capabilities are explicitly enabled by the user, not guessed from model names.
- Windows-encrypted saved keys, session-only keys, endpoint-scoped credential reuse and Forget connection. Keys stay out of project backups and public model responses.
- Serial tool execution, Stop, request timeouts, bounded conversation/tool loops, no automatic retries and actionable authentication/quota/model errors.
- AI editor topbar entry, clear provider/permission/cost information, and a native adapter loaded only for custom APIs.

Setup: open **AI editor → Custom API**, use the 9Router preset or enter a compatible endpoint, add the API key if required, then discover models or enter its exact model/combo ID. Start/configure your router separately. Enable images/reasoning only for supported models. Codex account sign-in remains available.

Cutline remains free and watermark-free. Custom providers may charge and receive the prompt/project context and permitted frames/transcripts; raw audio stays local. Compatibility requires OpenAI-style Chat Completions plus function/tool calling, not every proprietary API. Manual IDs are verified on the first message. Local mock integration tests do not prove every upstream model/provider works.

Download Setup to install or Portable to run without installing. Windows 10/11 x64 builds are unsigned and may trigger SmartScreen; verify SHA256SUMS.txt. This release does not automatically install or change your existing projects.

Verified: 97 unit/component checks, 31 native/protocol checks (including 10 custom-API tests), and 96 rendering/playback/export checks. The actual Windows window/preload/API/tool bridge passed a ten-point local mock workflow: discovery, encrypted storage, key privacy/clearing, title edit, real preview image, Undo, Forget connection and retained Codex setup. No real provider credentials or paid inference calls were used.
