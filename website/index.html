Let’s make Cutline better ↗

Is Cutline really free?

Yes. Core editing, effects and exports are free and watermark-free. Optional Codex editing uses your account limits; custom API providers may charge. Cutline does not sell a subscription.

Does it work offline?

Regular editing and exporting run locally. Subtitle and object-detection models need a one-time download. After downloading, those models run on your device. Codex and remote APIs need internet; a configured local API can run offline.

What about automatic subtitles?

Cutline uses local Whisper transcription with downloadable model sizes. Larger models need more memory and processing time. Choose 1–20 words per caption line, then review the generated subtitles before exporting. Shorter captions from Large use estimated timing within its segments.

How does disk-backed export help?

The Windows app writes encoded video to disk in small chunks instead of keeping the complete export in RAM. Choose a destination before rendering; the finished video replaces it only after validation succeeds. Browser downloads still use RAM. Source decoding, effects and codecs still need memory, so this is not a guarantee for every long project or PC.

Will scene detection find every edit?

It is designed for hard cuts. Sensitivity and minimum shot length are adjustable, and every suggested cut can be reviewed. Gradual dissolves or very brief shots may be missed.

Is this a replacement for every professional tool?

Cutline is an actively developed desktop editor, not a promise of feature parity with every commercial suite. Test a short export before a large project. The current color pipeline is not a professional HDR finishing workflow.

Can I use my own fonts and choose a theme?

Yes. The Windows app reads available installed fonts. Choose Graphite, Midnight, Forest or Light for your workspace, including its top bar.
